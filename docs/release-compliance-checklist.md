# Release Compliance Checklist

> M9 必备规格附件
> 创建日期：2026-06-03

---

## 1. Google Play 渠道

| 检查项 | 状态 | 说明 |
|--------|------|------|
| native executable 更新 | ⬜ | 不从外部下载替换；通过 App 版本更新携带 |
| Data Safety 表格 | ⬜ | 按 privacy-data-inventory.md 填写 |
| 隐私政策 URL | ⬜ | 需要独立隐私政策页面 |
| 目标 SDK 版本 | ⬜ | ≥ 35 (Android 15) |
| 权限声明 | ⬜ | INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE |
| 前台服务声明 | ⬜ | FOREGROUND_SERVICE + 用户可见通知 |
| 通知权限 | ⬜ | POST_NOTIFICATIONS (Android 13+) |

## 2. 企业/内测渠道

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 二进制下载 | ⬜ | 仅在合规确认后允许 |
| HTTPS 传输 | ⬜ | 所有二进制下载必须 HTTPS |
| 签名校验 | ⬜ | 下载后验证签名 |
| 哈希校验 | ⬜ | SHA256 校验 |
| 版本回滚 | ⬜ | 支持回退到旧版本 |
| 审计日志 | ⬜ | 记录更新操作 |

## 5. 广告 SDK 合规（未来）

## 6. 发布前验证

| 检查项 | 通过条件 |
|--------|----------|
| 功能完整 | 所有模块可操作 |
| 稳定性 | 旋转/后台/断网/取消不崩溃 |
| 数据正确 | 测试结果映射正确 |
| 权限最小化 | 不申请宽泛存储权限 |
| 可观测 | 错误码可诊断 |
| 回归测试 | 单元/集成/UI 测试通过 |
