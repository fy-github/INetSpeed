## 2. 脱敏规则

| 类型 | 规则 | 示例 |
|------|------|------|
| 公网 IPv4 | 报告默认保留；PNG 分享默认隐藏 | 192.168.1.100 → 192.168.*.** |
| 私网 IP | 默认可显示，导出前提示可能暴露内网结构 | 10.0.0.1 → 10.0.*.** |
| IPv6 | 同 IPv4 规则 | 2001:db8::1 → 2001:db8::**** |
| 域名 | 默认显示；导出前可选择隐藏 | hk-iperf.ikuai.com → hk-iperf.***.com |
| 路由跳点 | PDF/Excel 默认显示；PNG 默认隐藏 | 逐行替换 IP 为脱敏值 |
| MAC 地址 | 不采集真实硬件 MAC | 仅展示"随机 MAC/系统提供值" |
| 错误日志 | 不包含 token、header、账号 | 清理后保存 |

## 4. 同步策略

| 数据 | 同步方式 | 条件 |
|------|----------|------|
| 测试记录 | 自动增量同步 | 登录且 cloudSyncEnabled |
| 自定义服务器 | 自动增量同步 | 登录且 cloudSyncEnabled |
| 报告文件 | 手动触发 | 用户主动操作 |
| 设置 | 不同步 | 本地保存 |
| raw output | 不同步 | 本地保存 |

## 5. MAC 地址规则

- 不采集真实硬件 MAC 作为用户标识
- 不使用 MAC、IMEI、序列号、Android ID 组合做设备指纹
- 网络信息页展示"系统可见的网络标识状态"
- 如系统提供随机 MAC，标注"随机 MAC/系统提供值"
- 报告中默认不包含 MAC
